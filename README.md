# 360 Design Tulsa

Canonical website source for 360 Design & Construction LLC.

- Production: <https://360designtulsa.com/>
- Staging: <https://360design-staging.netlify.app/>
- Deployment source: the exact tested allowlisted artifact created from this repository

## Release controls

Changes are developed in the canonical E: project, committed to GitHub, deployed to the permanent Netlify staging project, independently reviewed, and promoted to production only after BC approves the exact tested artifact.

The repository intentionally excludes archives, provider-local metadata, deploy ZIPs, and non-publishing image evidence.
